Guarded Suspension(保护暂挂)模式
1. 角色分析
   - GuardedObject(被守护的对象)
   - GuardedObject 是一个持有被守护方法(guardedMethod)的类。
   - 当线程执行 guardedMethod 时，若守护条件成立，则可以直接执行；若守护条件不成立，就要进行等待。
   - 守护条件会随着 GuardedObject 的状态不同而发生改变。
   - 除了 guardedMethod 之外，GuardedObject 还有 stateChangeMethod 方法。
   - guardedMethod：通过 while 循环 + wait() 方法实现(防止虚假唤醒)。
   - stateChangeMethod：通过 notify() / notifyAll() 方法实现，用于唤醒等待中的线程。
