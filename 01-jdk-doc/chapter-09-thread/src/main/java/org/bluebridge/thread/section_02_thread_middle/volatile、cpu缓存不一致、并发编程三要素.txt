volatile、CPU 缓存不一致、并发编程三要素
1. volatile 关键字
   - 作用简述
     - 保证可见性：通过高速缓存一致性协议实现。
     - 保证有序性：通过内存屏障(内存栅栏)防止重排序。
   - 作用
     - 保证重排序的时候不会把后面的指令放在屏障的前面，也不会把前面的放到后面。
     - 强制对缓存的修改操作立即写入到主存。
     - 如果是写操作，会导致其他 CPU 中的缓存失效。
     - 保证不同线程之间的可见性。
     - 禁止对其进行重排序，也就是保证了有序性，但不能保证原子性。
         注意：i++ 并不是一个原子性操作，由两步组成：i = 10; i = i + 1(即 i = 10 + 1)。
   - 使用场景
     - 状态量标记。
     - 内存屏障前后的一致性。
2. 分析计算机如何完成 i=1; i++; 这个操作
   - 主要分为以下三步：
     a. read from main memory：i = 1
     b. i = i + 1
     c. i = 2
3. 缓存不一致问题
   - 从 main memory 中获取 i 的值为 1，把 i=1 放入到 cache 中，从 cache 中获取 i 的值为 1，进行 i++ 计算，得到 i = 2，把这个值回写到主存中。
   - 如果两个程序同时操作 i 这个数，进行 i++，那么可能会出现两个程序操作结果都是 2 的情况，而正确的结果应该是 3。
   - 解决方法
     - 给数据总线加锁
       总线分为数据总线、地址总线、控制总线。
     - CPU 高速缓存一致性协议
       a. 当 CPU 写入数据的时候，如果发现该变量被共享(也就是说在其他 CPU 中也存在该变量的副本)，会发出一个信号，通知其他 CPU 针对该变量的缓存无效。
       b. 当其他 CPU 访问该变量的时候，重新到主内存中进行获取，类似于数据库事务中的串行读取。
4. 并发编程中三个比较重要的概念
   - 原子性
     - 一个操作或者多个操作，要么都成功，要么都失败，中间不能由于任何的因素中断。
     - 注意事项：
       a. 所有基本类型赋值以及读取都是原子性的
            赋值：int x = 1;
            读取：System.out.println(x);
       b. 引用类型数据赋值也是原子性的
            如：Object o1 = new Object();
            赋值：Object o2 = o1;
   - 可见性
       使用 volatile 保证内存可见性。
   - 有序性
       重排序要求最终结果一致性。
