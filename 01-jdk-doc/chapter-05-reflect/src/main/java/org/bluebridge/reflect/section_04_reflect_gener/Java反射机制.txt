Java 反射机制
1. 动态语言
   - 程序运行时，可以改变程序结构或者变量类型，典型的语言：JavaScript、Ruby、Python。
   - C、C++、Java 不是动态语言，但是 Java 有一定的动态性，我们可以利用反射机制、字节码操作获得类似于动态语言的特性，Java 的动态性让编程更加灵活。
2. 反射机制
   - 指的是可以在运行时加载、探知、使用编译期间完全未知的类。
   - 程序在运行状态中，可以动态地加载一个只有名称的类；对于任意一个已经加载的类，都能获取这个类中所有的属性和方法；对于任意一个对象，都可以调用其方法和属性。
   - 加载完类之后，在堆内存中，就产生了一个 Class 类型的对象(一个类只有一个 Class 对象)，这个对象就包含了完整的类的结构信息，可以通过这个对象看到类的结构。
   - 这个 Class 对象就像一面镜子，透过这面镜子可以看到类的结构，所以我们形象地称之为反射。
3. 反射机制的常见作用
   - 动态加载类，动态获取类的信息(属性、方法、构造器)
   - 动态构造对象
   - 动态调用类和对象的任意方法、构造器
   - 动态调用和处理属性
   - 获取泛型信息
   - 处理注解
4. 反射深入理解
   - 每个类只能产生一个 Class 对象。
   - 原因：当我们运行一个类时，首先会检测 JVM 内存中是否存储着类的结构信息；假如没有存储，会由类加载器将类读到内存，存储到 JVM 的方法区(存储的是类的结构信息)，同时在加载过程中会创建一个 Class 对象(类对象)。
   - 类的加载器(ClassLoader)
