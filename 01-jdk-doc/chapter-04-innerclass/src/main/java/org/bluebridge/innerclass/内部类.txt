1. 内部类概述
   - 内部类：将一个类的定义放在另一个类的内部。
   - 四种内部类：成员内部类、静态内部类、局部内部类(方法内部类)、匿名内部类
2. 内部类好处
   - 内部类可以有多个实例，每个实例都有自己的状态信息，并且与其他外围对象的信息相互独立。
   - 内部类并没有令人迷惑的 “is-a” 关系，它就是一个独立的实体。
   - 内部类提供了更好的封装，除了该外围类，其他类都不能访问。
   - 创建内部类对象的时刻并不依赖于外围类对象的创建。
   - 每个内部类都能独立地继承一个(接口的)实现，所以无论外围类是否已经继承了某个(接口的)实现，对于内部类都没有影响。
3. 内部类具有类的基本特征
   - 可以继承一个类或者实现一个接口。
     public class Outer extends ClassA implements IFunctionA {
         public class Inner extends ClassB implements IFunctionB {
             // ...
         }
     }
4. 成员内部类
   - 成员内部类当成 Outer 的成员信息存在。
   - 可以使用任意的访问修饰符。
   - 内部类的内部不能有静态信息。
   - 内部类也是类，该继承继承，该重写重写，该重载重载，this 和 super 随便用。
   - 外部类访问内部类信息，必须 new 之后打点访问。
   - 内部类可以直接使用外部类的任何信息；如果属性或者方法发生冲突，通过 外部类.this.属性(方法) 显式调用。
   - 其它类如何访问内部类：
     Outer outer = new Outer();
     Outer.Inner inner = outer.new Inner();   // 先创建外部类对象，再创建内部类对象
     inner.inner_show();
5. 静态内部类
   - 与成员内部类对比理解(区别异同)。
   - 内部可以包含任意的信息。
   - 静态内部类的方法只能访问外部类的 static 关联的信息。
   - 创建方式：外部类.内部类 引用 = new 外部类.内部类(); 然后通过引用访问成员信息(属性、方法)。
   - 访问内部类的静态信息，直接 外部类.内部类.静态信息 即可。
   - 静态内部类可以独立存在，不依赖于外围类对象。
6. 局部内部类
   - 定义在方法内，有较多局限，应注意作用域。
   - 类前不能有访问修饰符。
   - 仅在此方法内使用。
   - 无法创建静态信息。
   - 可以直接访问方法内的局部变量和参数(有限制：必须是被 final 或 effectively final 修饰的变量)，但是不能更改。
   - 可以随意访问外部类的任何信息。
7. 匿名内部类
   - 没有类名的局部内部类，在创建对象时直接定义。
   - 必须继承一个父类或实现一个接口(且只能一个)。
   - 没有类名，不能定义构造方法(可以通过实例代码块做初始化)。
   - 与局部内部类一样，只能访问 final / effectively final 的局部变量。
   - 典型场景：new Runnable() { ... }，new Thread() { ... }，以及各种回调接口。
